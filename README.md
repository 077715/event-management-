# Online Event Registration Portal

A modern web-based Event Registration Portal that allows users to browse, register, and manage event participation online. The platform simplifies event handling for both organizers and participants with an interactive and user-friendly interface.

---

## 🚀 Features

- User Registration & Login
- Event Listings
- Online Event Registration
- Responsive User Interface
- Form Validation
- Interactive Dashboard
- Secure Data Handling
- Modern UI Design

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/077715/event-management-.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd event-management-
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Server

```bash
npm start
```
